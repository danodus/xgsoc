Features
========

- RISC-V (RV32IMFC)
- UART (1000000-N-8-1)
- SDRAM (32MiB shared between CPU and video)
- Set associative cache (4-way with LRU replacement policy)
- VGA (60 Hz) HDMI video output with framebuffer (RGB565). The ZOOM register can show that framebuffer at full size, half size, or quarter size in any video mode
- 720p (60 Hz) or 1080p (30 Hz) video modes (experimental)
- Graphite 2D/3D graphics accelerator (textured triangles)
- PS/2 Keyboard
- PS/2 Mouse
- USB host for keyboard and mouse (experimental)
- SD Card with hardware SPI
- HDMI stereo PCM audio (48 kHz)
